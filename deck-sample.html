01   클로드 코드 이해하기

내 프로젝트에서 함께 작업하는
AI 코딩 도구

Claude Code는 파일을 읽고, 코드를 수정하고, 필요한 명령을 실행합니다.

01

프로젝트 파악

폴더 구조와 코드의 역할을 읽고
초보자도 이해할 수 있게 설명합니다.

02

코드 수정

한국어로 설명한 요구사항을 바탕으로
기능을 추가하거나 오류를 고칩니다.

03

결과 확인

실행과 테스트를 요청하고,
완성한 기능은 직접 확인합니다.

처음 입력해 볼 요청
“이 프로젝트의 목적과
폴더 구조를 초보자에게
설명해줘.”

첫 요청에는 이렇게 덧붙여 보세요.
“수정은 하지 말고 실행 방법부터 알려줘.”

02   설치하고 로그인하기

Windows에서 설치와 첫 실행

시작 메뉴에서 PowerShell을 열고, 아래 명령을 순서대로 입력합니다.

01 공식 설치 스크립트 실행
irm https://claude.ai/install.ps1 | iex

공식 서버에서 설치 스크립트를 내려받아 실행합니다.

02 새 PowerShell 창에서 설치 확인
claude --version
03 실습 폴더를 만들고 시작
mkdir claude-first-project
cd claude-first-project
claude

이미 같은 이름의 폴더가 있다면 다른 이름을 사용하세요.

시작 전 확인

계정과 인터넷 연결

Claude Code 사용 권한이 있는 계정이 필요합니다. 구독 이용과 Console API 과금은 구분해 확인하세요.

첫 실행 후 로그인

화면 안내에 따라 로그인하고, 현재 작업 폴더가 맞는지 확인합니다.

입력 위치 구분

설치 명령은 PowerShell에,
한국어 요청은 실행된
Claude Code 입력창에 씁니다.
